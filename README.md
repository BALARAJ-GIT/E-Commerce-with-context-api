## 🚀 About The Project

**ShopEase** is a modern e-commerce web application developed using React.

The application fetches real product data from the FakeStore API and displays products in an attractive card layout.

Users can browse products, add items to their shopping cart, increase or decrease quantities, and view their total purchase amount.

The project focuses on practical React development concepts, reusable components, API integration, and global state management.
